SYIVORA STORE — WEBSITE COMPANY PROFILE

Struktur:
- index.html       : Beranda
- about-us.html    : Tentang Kami
- kontak.html      : Kontak
- portofolio.html  : Portofolio
- produk.html      : Produk
- css/style.css    : Seluruh styling
- js/script.js     : Interaksi menu, filter produk, dan formulir demo

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Buka index.html di browser, atau gunakan ekstensi Live Server.
4. Semua halaman terhubung melalui menu navigasi.

Catatan:
- Nama, harga, email, Instagram, dan ilustrasi produk adalah contoh yang bisa diganti.
- Formulir kontak hanya demo front-end dan belum mengirim email / menyimpan data.
- Font Google membutuhkan koneksi internet; jika offline, font cadangan akan digunakan.
